# Where real complaints about Indian brands can come from

Research behind WTF's receipts (wtf.topc.social), October to November 2026.

- [india-complaint-data.md](india-complaint-data.md): open and legal sources of Indian consumer complaints by brand. Governments publish counts, not text. Tasks #9.
- [e-jagriti-bulk.md](e-jagriti-bulk.md): can district consumer court orders be pulled from e-Jagriti for free? Partly: the search exists but a captcha guards every query. The site's API details are left out of this public copy. Task #12.
- [common-crawl-indigo.md](common-crawl-indigo.md): Common Crawl as a free complaint index. 46,666 links from one site; that site deletes old complaints, the Wayback Machine keeps most of them. Task #13.

Built from this: tasks #10, #11, #14, #15.
